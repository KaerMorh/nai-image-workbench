# NovelAI Toolbox – Queue & Prompt Batch

`novelai-toolbox.user.js` 是面向 Chrome + Tampermonkey 的单文件 NovelAI 图片生成队列脚本。

## 本地开发

开发时只需安装一次 `novelai-toolbox.dev.user.js`，并停用普通安装的脚本副本。加载器通过 Tampermonkey 官方支持的本地 `@require` 工作流读取 `novelai-toolbox.user.js`，以后修改源码后刷新测试页即可生效，不需要重新安装。

## 当前功能

- NovelAI 空闲时，Generate 保持原始行为，不记录普通生成。
- NovelAI 正在生成或队列已有任务时，再次点击 Generate 会捕获当时的完整请求并排到队尾。
- 点击时冻结 prompt、模型、参数和图片引用；等待期间继续修改页面不会污染已记录任务。
- 请求、响应解析、主画面与 History 更新仍交给 NovelAI 原始代码处理。
- 支持暂停、继续、删除、清空、重新入队、跨标签页共享和排他执行。
- 提示可选择右下角、右上角或完全关闭；未关闭时仍可点击立即消失。
- 可选在右侧 History 缩略图右下角显示保存状态小标识：已保存为绿色，未保存及生成中为红色；标识不接收指针事件，不影响切图。
- 独立“批量替换”模式读取 Base Prompt 中唯一一种 `{{变量}}`，把逐行列表依次替换进去并串行生成。
- 批量模式冻结启动时的完整请求配置（包括图生图、Vibe 与精确参考），每项继续使用不同随机 seed。
- 当前批量单位成功后才会移除；暂停后可编辑剩余行，最终失败会保留当前单位并提供重试或跳过。
- 批量列表最多 500 项；用户刷新页面后只恢复数据并保持暂停，绝不会自动重发结果不明的项目。
- 等待任务与已结束记录保存在 IndexedDB；参考图等大字段按 SHA-256 去重。
- 已结束记录最多保留 100 条，超过后自动删除最旧记录。
- 429 和连接失败按 5/15/30 秒重试；超时或永久错误会暂停队列。
- 每一次队列发送和重试都会重新生成随机 seed，其他配置保持不变。
- 插件不会调用刷新或导航 API。

## 安装

1. 在 Chrome 安装 Tampermonkey。
2. 新建用户脚本。
3. 用 `novelai-toolbox.user.js` 的全部内容替换编辑器内容并保存。
4. 打开或重新进入 `https://novelai.net/image`。

## 运行限制

- 至少需要保留一个 NovelAI 图片页面。关闭 Chrome 或所有匹配页面后，油猴脚本无法继续执行；队列数据仍会保留。
- Chrome 的内存节省程序若冻结页面，执行会暂时停住，并在页面恢复后继续。
- 刷新时正在生成的远端请求无法可靠判定是否完成，因此不会自动重复发送。
- NovelAI 官方接口要求每次生成由用户动作发起；每个队列记录都来自一次用户点击，脚本只做串行调度。
