# 使用说明

README 只介绍最核心的工作流。本页记录 NAI Image Workbench 的完整行为、设置和常见问题。

## 等待队列

### 什么时候会加入队列

- NovelAI 空闲且队列为空时，Generate 保持网站原始行为，不创建队列记录。
- NovelAI 正在生成或队列已有任务时，Generate 会显示为蓝色；点击后记录当前配置并加入队尾。
- 暂停队列后，Generate 恢复原始行为，不再把点击转成排队操作。

### 每个任务会保存什么

任务记录生成请求中的 Prompt、模型、分辨率、采样器、步数、Guidance、数量和参考图片等完整配置。

参考图片等较大的二进制字段会保存在浏览器 IndexedDB 中，并按内容去重。任务执行或重试时只重新生成随机 Seed。

### 重试和失败

- 429 和网络连接失败会按照设置自动重试。
- 默认最多重试 3 次，等待时间依次为 5、15 和 30 秒。
- 服务端错误会交由队列判断并暂停，避免持续发送无效请求。
- 超时或无法安全归类的错误会暂停队列，并保留任务供手动处理。

### 队列操作

- **暂停/继续**：控制等待任务是否继续派发。
- **删除**：删除单个队列记录，不操作 NovelAI History。
- **全部删除**：只清空当前队列或已结束记录。
- **重新入队**：使用已结束任务保存的配置创建新的等待任务。

## 批量 Prompt 替换

Base Prompt 必须包含形如 `{{name}}` 的占位符。一个批次只能使用一种名称，但它可以在同一 Prompt 中重复出现。

替换列表以换行为单位，空行会被忽略，重复行会原样保留。启动后，脚本冻结完整请求配置，并按列表顺序逐项处理。

### 运行规则

- 当前单位成功后才会从剩余列表中移除。
- 当前单位生成期间可以点击暂停；它结束后，批次不会继续下一项。
- 暂停状态下可以编辑尚未处理的列表。
- 最终失败时保留当前单位，可以重试或跳过。
- 页面刷新后保留批次数据，但保持暂停，避免重复生成结果不明的项目。
- 每个单位和每次重试都会使用新的随机 Seed。

## History 保存状态

开启后，每个 History 缩略图右下角会显示一个小圆点：

- 绿色表示 NovelAI 已经将该图片标记为保存。
- 红色表示尚未保存，或图片仍在生成。

状态判断沿用 NovelAI 自己的下载按钮状态。标识不接收指针事件，不会阻挡缩略图切换，也不会下载、删除或修改 History 内容。

## 设置

| 设置 | 作用 |
| --- | --- |
| 启用等待队列 | 关闭后不接管 Generate，也不派发后续任务 |
| 自动重试次数 | 控制 429 和连接失败的重试次数，范围 0–3 |
| 任务间隔 | 前一任务结束后到下一任务开始前的等待时间 |
| 已结束记录上限 | 保留最近 10–100 条记录，超出后删除最旧记录 |
| 提示位置 | 右下角、右上角或完全关闭 |
| 普通提示停留 | 控制普通通知自动消失的时间；仍可点击立即关闭 |
| History 保存状态 | 控制右下角红绿状态标识 |

面板和设置窗口都可以拖动，位置会保存在浏览器中。

## 数据与清理

队列、设置和批次状态保存在 `novelai.net` 站点范围内的 IndexedDB 中。卸载用户脚本不会自动删除这些数据。

如需彻底清除：

1. 打开 Chrome 开发者工具。
2. 进入 Application → Storage。
3. 选择 `novelai.net`。
4. 清除名为 `nai-image-workbench` 的 IndexedDB 数据库。

这会永久删除工具保存的队列、批次和已结束记录，但不应操作 NovelAI 自己的 History。清理前请自行确认不再需要这些数据。

## 多标签页

多个 NovelAI 图片标签页共享同一份队列。脚本使用跨标签页同步和排他锁，确保同一时间只由一个页面发送任务。

至少需要保留一个可运行的 NovelAI 图片页面。页面被浏览器冻结时，队列会暂时停止，并在页面恢复后继续。

## 常见问题

### 刷新后队列还在吗？

还在。等待任务和批次数据会保留；结果不明的运行中任务会暂停，等待人工确认。

### 支持哪些 NovelAI 模型？

脚本记录页面实际产生的请求，不维护独立的模型列表。NovelAI 前端结构或请求格式变化后，可能需要更新脚本。

### Firefox 可以使用吗？

当前只在 Chrome 与 Tampermonkey 工作流下开发。Firefox 未做兼容性保证。

### 是否需要特定 NovelAI 订阅？

脚本不会绕过 NovelAI 的账号、订阅、额度或生成限制。能够在原网页正常生成，是使用队列的前提。

### 插件会刷新页面吗？

不会。用户脚本不调用页面刷新或导航 API。
