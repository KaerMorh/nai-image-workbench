# Chunks 自动备份到 GitHub

这是一个独立的 Tampermonkey 脚本。从 NovelAI 单向备份到你指定的 GitHub 私有仓库，不会从 GitHub 回写账号。

1. 准备一个已初始化（至少有一次提交）的 GitHub **Private** 仓库。创建 fine-grained personal access token，仓库范围只选该仓库，权限选 **Contents: Read and write**。默认分支需要允许该令牌直接提交。
2. 在 Tampermonkey 新建脚本，把 [nai-chunks-github-sync.user.js](../nai-chunks-github-sync.user.js) 的全部内容粘贴进去并保存。打开或刷新 NovelAI 图像页。
3. 刷新 NovelAI 图像页，在 **Chunks 同步 → 设置** 中填写私有仓库和令牌，点击 **保存并同步**。面板默认位于右上角，拖动标题可移动，位置会自动保存。旧版已保存的有效令牌可留空沿用。
4. 面板显示当前操作和上次核对成功时间。点击 **立即同步** 可重新读取并比较当前 Chunks；成功后用 **查看 GitHub 备份** 核对文件。

以后每次进入 NovelAI 图像页，脚本会等待账号加载 Chunks，直接读取指定仓库默认分支的 `novelai/prompt-chunks.json`。正文、名称、颜色和分组排序记录有变化时才提交；该路径已有其他格式的文件时会停止。Git 的提交历史保留旧版本。分组不必展开，也不需要打开 Chunks 面板。

遇到 **HTTP 401** 时，脚本保留令牌，并自动用同一令牌请求一次 GitHub 用户接口，区分用户认证和仓库请求的结果。两处均为 401 时会显示可用的 GitHub 请求编号；缺少编号时也不能直接断定响应来自代理。脚本不会自动循环重试。也可在 **设置 → 检查认证** 中单独检查：使用输入框内的令牌，留空时使用已保存令牌，不保存更改或写入仓库。

油猴菜单的 **查看同步状态** 显示本页结果；网络失败、分支受保护、令牌过期或页面加载超时后可用 **立即同步** 重试。空列表或分组引用缺失不会覆盖旧备份。脚本读取当前已登录的 NovelAI 账号；若同一浏览器切换账号，请先停用或改配仓库。**停用同步并清除令牌** 移除本机配置；如需撤销令牌，请到 GitHub 删除该令牌。

脚本不检查仓库是否私有，也不请求仓库信息接口；读取备份路径返回 404 时尝试创建文件，写入返回 404 时显示仓库名称及访问权限提示。
